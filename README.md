# kosio-labs Homebrew tap

Homebrew casks for apps by Kosio.

```sh
brew install --cask kosio-labs/tap/<cask>
```

## Casks

- [`poprostu`](https://github.com/kosio-labs/poprostu) — po prostu, an image
  viewer for fast RAW browsing with colour management. macOS 15 or later.

## Quarantine

These apps are not signed with an Apple Developer ID and not notarised. The
casks remove the macOS quarantine flag after installing, so Gatekeeper lets
the app open. This means macOS does not run its own malware check on it.
Install only if you trust this source.
